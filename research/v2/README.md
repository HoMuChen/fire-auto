規範（期間、事前登記、成本、過關標準）見根目錄 `AGENTS.md`「研究規範」。每個假設的完整登記與數字在 `HYPOTHESES.md`，每次執行的紀錄在 `experiments.jsonl`。

| 檔案 | 用途 |
|------|------|
| `harness.py` | 核心：`PERIODS`、`universe()`、`load_stock()`、逐檔 `simulate()`（次日開盤、一字漲跌停、下市出場）、`leak_check()`、`run()`（含隨機進場基準） |
