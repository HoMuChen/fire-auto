# research/v2 — 防前視研究框架（2026-10-20 起）

規範（期間、事前登記、成本、過關標準）見根目錄 `AGENTS.md`「研究規範」。**新研究先從特徵庫 `FEATURES.md` 取原料**：依用途（排序、多空、挑贏家、避雷）貼標籤，dev 給標籤、val 確認，`◎✓✓` 最可靠。每個假設的完整登記與數字在 `HYPOTHESES.md`，每次執行的紀錄在 `experiments.jsonl`。

**接手找新特徵**：先讀 `FEATURE_PLAN.md`（2026-11-03 擬定的分階段計畫；階段 0～3 已完成）。下一批候選在 `FACTOR_MAP.md`（JKP 153 個學術因子和本專案的對照表）。

**接手用特徵找策略**：先讀 `STRATEGY_PLAN.md`（2026-11-03 擬定的分階段計畫；S0～S2 已完成；只要比基準好、不和 H136 比）。

**接手多策略合併**：先讀 `PORTFOLIO_PLAN.md`（2026-11-04 擬定；P0、P1 已完成〔第五十八批〕：在不放空個股的限制下，避險多頭在每個載體都是負的，P3 不做，下一步等使用者決定）。
